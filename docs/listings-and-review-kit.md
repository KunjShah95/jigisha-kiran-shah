# 6. REVIEW-REQUEST KIT (WhatsApp — highest ROI activity)

**Golden rules**
- Ask within 24h of a happy moment (claim paid, policy issued, renewal saved, clear explanation given)
- Send the DIRECT Google review link (GBP dashboard → "Ask for reviews" button → copy link — use that short link, NOT a share.google search link)
- Never ask for "5 stars"; ask for "your honest experience"
- Never send to more than ~5 people/week from the same phone (WhatsApp spam filter)
- Ask them to mention **the service + their area** — that text is a ranking signal
